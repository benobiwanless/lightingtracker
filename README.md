# Central Florida Lightning Map

A minimal GitHub Pages site that displays the live Blitzortung vector lightning map full-screen, centered at 28.0711, -81.8725.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub Pages will provide the public website URL.

## Map settings

The map is configured with the documented Blitzortung embedding parameters to hide advertising, information panels, cookies, menu button, and scale control while retaining an interactive map.

Lightning data and map service remain provided by Blitzortung.org / LightningMaps.org.
